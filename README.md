# Web Stack
Навчальна майстерня українською: HTML, CSS, JavaScript. 31 інтерактивний приклад.

## Запуск
Розпакуйте архів і відкрийте index.html у браузері. Усі файли мають залишатися разом. Інтернет, сервер та встановлення пакетів не потрібні.

## GitHub Pages
1. Створіть репозиторій або відкрийте наявний.
2. Add file → Upload files. Завантажте вміст папки: index.html, style.css, lessons.js, app.js (і за бажанням README.md). index.html має лежати в корені репозиторію.
3. Commit changes.
4. Settings → Pages → Deploy from a branch → main → / (root) → Save.
5. Після завершення публікації відкрийте адресу, яку покаже GitHub Pages.

## Як працювати
Оберіть розділ → рівень → приклад. HTML, CSS та JS редагуються окремо. «Запустити» або Ctrl+Enter створює результат заново. Консоль показує повідомлення та помилки JS. Кнопка «Мій приклад .html» зберігає самодостатній файл з усіма трьома частинами.
Позначки проходження — самооцінка, а не автоматичний тест. Чернетки й позначки зберігаються в localStorage цього браузера, якщо він це дозволяє. У приватному режимі чи після очищення даних вони можуть зникнути.

## Структура
- index.html — інтерфейс
- style.css — оформлення
- lessons.js — зміст 31 прикладу
- app.js — редактори, запуск, консоль, експорт і прогрес

## Важливі пояснення
Результат запускається в iframe з sandbox="allow-scripts" без доступу до основної сторінки. Зовнішня навігація, форми та інші можливості вбудованого вікна обмежені. Навчальні форми не надсилають дані.
JavaScript змінює DOM, стилі та стан програми в пам’яті. «JS змінює JS» демонструє заміну функції та перемикання логіки; вихідні файли не переписуються.
Використовуйте раннер для коротких навчальних експериментів. Нескінченний цикл може заблокувати вкладку: закрийте її та відкрийте сайт повторно.

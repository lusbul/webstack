КОД — ЦЕ ЕКСПЕРИМЕНТ

Почніть із маленької зміни.

Не потрібно одразу писати все з нуля. Змініть слово, колір або число — і подивіться, що сталося.

  1. Оберіть розділ і приклад. Прочитайте коротке пояснення.
  2. Перемикайте HTML / CSS / JS. Усі три частини одного прикладу можна редагувати.
  3. Запустіть код. Кнопка або Ctrl + Enter оновить результат. Для повзунків і кнопок натискайте всередині результату.
  4. Виконайте експеримент. Позначка проходження — ваша самооцінка, не автоматична перевірка.
  5. Збережіть власну роботу. «Мій приклад .html» завантажує окрему готову сторінку.

Що змінює JavaScript?

Вміст, стилі й поведінку поточної сторінки в пам’яті браузера. Вихідні файли на диску самі не переписуються.

Що робить «Запустити»?

Створює результат заново. Змінні й дії в попередньому запуску скидаються. Ваш код у редакторі зберігається.

Хочете вийти за межі прикладу?

Завантажте свій HTML та відкрийте в браузері. Посилання й надсилання форм у вбудованому раннері обмежені.
